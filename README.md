# ChefaAudaz!

Aplicación para Windows con navegador de juego integrado, cuadrícula para marcar objetivos y clics en segundo plano.

## Descargar

[**Descargar ChefaAudaz! Windows 3.1 · ZIP**](https://github.com/chefahere/ChefaAudaz-descargas/releases/download/v3.1.0/ChefaAudaz-Windows-v3.1.zip)

[Ver la publicación y las instrucciones](https://github.com/chefahere/ChefaAudaz-descargas/releases/tag/v3.1.0)

Extrae el ZIP, cierra la versión anterior, abre **ChefaAudaz-Windows.exe**, pulsa **Abrir juego** e inicia sesión en tu cuenta del juego dentro de esa ventana. El juego se abre maximizado y se ajusta automáticamente al redimensionar la ventana. **F11** activa pantalla completa y F11 o Esc regresa. Elige el tamaño antes de usar **Marcar puntos · cuadrícula** y configurar los tiempos.

Si cambias de tamaño después de marcar, la secuencia se detiene y debes marcar otra vez. Ocultar o minimizar conserva las coordenadas para continuar en segundo plano.

Admite clic izquierdo y derecho, varios objetivos, segundos/minutos/horas, repetición infinita y minimización al panda junto al reloj. **Ctrl + Alt + S** detiene; **F8** inicia o detiene.

Windows 10/11 de 64 bits. La guía y el instalador oficial de WebView2 están incluidos. Cada usuario conserva su propia configuración y sesión en su equipo.
