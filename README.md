# ChefaAudaz!

Aplicación para Windows con navegador de juego integrado, cuadrícula para marcar objetivos y clics en segundo plano.

## Descargar

[**Descargar ChefaAudaz! Windows 3 · ZIP**](https://github.com/chefahere/ChefaAudaz-descargas/releases/download/v3.0.0/ChefaAudaz-Windows-v3.zip)

[Ver la publicación y las instrucciones](https://github.com/chefahere/ChefaAudaz-descargas/releases/tag/v3.0.0)

Extrae el ZIP, abre **ChefaAudaz-Windows.exe**, pulsa **Abrir juego** e inicia sesión en tu cuenta del juego dentro de esa ventana. Usa **Marcar puntos · cuadrícula** para seleccionar los objetivos y configurar los tiempos.

Admite clic izquierdo y derecho, varios objetivos, segundos/minutos/horas, repetición infinita y minimización al panda junto al reloj. **Ctrl + Alt + S** detiene; **F8** inicia o detiene.

Windows 10/11 de 64 bits. La guía y el instalador oficial de WebView2 están incluidos. Cada usuario conserva su propia configuración y sesión en su equipo.
